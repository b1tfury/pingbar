# PingBar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS menu bar app showing live ICMP latency to the nearest anycast PoP with a green/yellow/red indicator.

**Architecture:** Swift Package executable. `ICMPPinger` sends echo requests over an unprivileged ICMP datagram socket; `LatencyMonitor` samples on a timer into a rolling window and classifies status; `StatusBarController` renders an `NSStatusItem` and dropdown menu. Pure functions (packet build, checksum, classify, window stats) are unit-tested.

**Tech Stack:** Swift 5.9+, AppKit, ServiceManagement, Darwin sockets, XCTest, Make.

## Global Constraints

- macOS 13+, `swift build` only, no Xcode project, no third-party packages.
- Default interval 5 s; allowed 3/5/10 s. Payload 56 bytes (64-byte ICMP incl. header).
- Thresholds: green `< 60 ms`, yellow `< 150 ms`, red otherwise / timeout / error.
- Targets: `1.1.1.1` (default primary), `8.8.8.8`. Fallback = the other one.
- Window size 12 samples. Ping timeout 2.0 s.

### Task 3: ICMPPinger (socket I/O)

**Files:**
- Create: `Sources/PingBarCore/ICMPPinger.swift`

**Produces:** `final class ICMPPinger { init(host: String); func ping(timeout: TimeInterval) -> PingResult }`

- [x] Implement: `socket(AF_INET, SOCK_DGRAM, IPPROTO_ICMP)`; `inet_pton` host; per-ping `sendto` of `ICMPPacket.echoRequest`; `poll` loop until deadline; `recvfrom` into 1024-byte buffer; if byte0>>4 == 4 skip IP header `(byte0 & 0x0F)*4`; accept type 0 with matching id+seq → `.rtt`; otherwise keep waiting; deadline → `.timeout`; socket failure → `.error(strerror)`.
